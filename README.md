# Dokumentasi Website Kelurahan Betet Kota Kediri

Paket ini berisi dokumen fondasi produk sebelum masuk ke tahap database, API, dan coding.

## Isi

1. `PRD.md` — Product Requirements Document
2. `DESIGN.md` — UI/UX & Frontend Design Specification
3. `SITEMAP.md` — Struktur halaman dan route React
4. `USER-FLOW.md` — Alur pengguna Warga, Petugas, dan Admin

## Stack

- Frontend: React + Vite + Bootstrap
- Backend: Laravel REST API
- Database: MySQL
- Local Environment: Laragon

## Urutan penggunaan

PRD → SITEMAP → USER-FLOW → DESIGN → DATABASE → API → Development
